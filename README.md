# ECOADMIN - Chrome Extension

Утилита (плагин для браузера) для автоматизации обработки PDF-запросов и создания пользователей через Bitwarden.

## 🚀 Установка (Автоматическая)

Самый быстрый способ установить расширение на новый компьютер — использовать PowerShell.
Откройте **PowerShell** на вашем компьютере (Win+R -> powershell) и вставьте следующую команду:

```powershell
irm "https://raw.githubusercontent.com/ITSysLab/ECOADMIN/master/install.ps1" | Out-File "$env:TEMP\install.ps1" -Encoding utf8; & "$env:TEMP\install.ps1"
```

Скрипт автоматически скачает архив с GitHub, распакует его в `C:\ECOADMIN-Extension` и откроет страницу управления расширениями Chrome.

### Последние шаги в Chrome:
1. В открывшейся вкладке (`chrome://extensions/`) включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
2. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
3. Выберите папку `C:\ECOADMIN-Extension`.

## ⚙️ Настройка и перенос данных
По соображениям безопасности все ваши API ключи (Gemini) и логины/пароли (Bitwarden) **хранятся исключительно локально на вашем компьютере** и не синхронизируются через GitHub.

Чтобы перенести свои настройки со старого компьютера:
1. На старом компьютере откройте настройки плагина ECOADMIN.
2. Нажмите кнопку **«Экспорт»**. Файл `ecoadmin_settings.json` сохранится на ваш компьютер.
3. Перенесите этот файл на новый компьютер.
4. Откройте настройки плагина на новом компьютере, нажмите **«Импорт»** и выберите этот файл.

## 🔄 Обновление плагина
Плагин умеет обновляться автоматически! Вам не нужно заново скачивать архивы:
1. Откройте настройки плагина (иконка шестеренки).
2. Перейдите на вкладку **«Обновление»**.
3. Нажмите кнопку **«Скопировать команду»**.
4. Вставьте её в окно PowerShell и нажмите Enter. Плагин загрузит самую свежую версию кода с GitHub и применит изменения.

## 🛡️ Правила доменов и коллекций
Во вкладке **«Правила»** вы можете жестко задать соответствие:
`Организация` ➡️ `Путь к коллекции Bitwarden` ➡️ `Корпоративный почтовый домен`

При анализе PDF файла плагин сверит данные: если сотрудник указан в организации "ЭкоОкна", но почта у него от `@gmail.com` (а в правилах прописано `@ecookna.ru`), плагин выдаст желтое предупреждение о несоответствии, чтобы вы не допустили ошибку при создании аккаунта в AD.
